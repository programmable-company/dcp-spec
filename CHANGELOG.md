# Changelog

## 2026-05-04

Project renamed to **Programmable Company** (previously the Agentic Company Protocol; the project itself was briefly named the Declarative Company Protocol during a renaming pass before the project/specification split was settled). Repository moved to `programmable-company/dcp-spec`. Project home: <https://programmable.company>.

First specification, the **Declarative Company Protocol** (DCP), draft `2026-05-04`, published. DCP is the data-layer specification — the intermediate step before the future programmable-layer specification under the same project. Sources: [`specification/2026-05-04/`](specification/2026-05-04/) (prose) and [`schema/2026-05-04/`](schema/2026-05-04/) (TypeScript and generated JSON Schema). The draft scopes the data shape of a conforming repository, JCS canonicalization, JWS/JAdES signing, capability declaration, and date-based versioning. The interaction/runtime layer is explicitly deferred to the future programmable-layer specification.

Estonia profile skeleton added under [`profiles/estonia/`](profiles/estonia/). Specification Enhancement Proposal (SEP) template added under [`seps/`](seps/).

## 2026-04-22

Initial public repository. Vision and principles published; specification work to follow.
