# Changelog

## 2026-05-04

Project renamed to **Programmable Company** (previously the Agentic Company Protocol; briefly the Declarative Company Protocol). Repository moved to `programmable-company/spec`.

First specification draft published under [`specification/2026-05-04/`](specification/2026-05-04/), with the corresponding TypeScript schema and generated JSON Schema under [`schema/2026-05-04/`](schema/2026-05-04/). The draft scopes the *declarative* layer of Programmable Company: the data shape of a conforming repository, JCS canonicalization, JWS/JAdES signing, capability declaration, and date-based versioning. The interaction/runtime layer is explicitly deferred.

Estonia profile skeleton added under [`profiles/estonia/`](profiles/estonia/). Specification Enhancement Proposal (SEP) template added under [`seps/`](seps/).

## 2026-04-22

Initial public repository. Vision and principles published; specification work to follow.
