# Changelog

## 2026-05-04

Project umbrella named **Programmable Company**, hosted at <https://programmable.company>. The protocol underlying this work was originally drafted as the Agentic Company Protocol and then renamed to the Declarative Company Protocol (commit `bd56929`). With this draft, the project / specification split is settled: *Programmable Company* is the name of the project, and *Declarative Company Protocol* (DCP) is the name of its first specification — the data layer. Repository moved from `the-agentic-company/acp-spec` to `programmable-company/dcp-spec`.

First DCP draft, `2026-05-04`, published. Sources: [`specification/2026-05-04/`](specification/2026-05-04/) (prose) and [`schema/2026-05-04/`](schema/2026-05-04/) (TypeScript and generated JSON Schema). Scopes the data shape of a conforming repository, JCS canonicalization, JWS/JAdES signing, capability declaration, and date-based versioning. The interaction/runtime layer is deferred to the future programmable-layer specification, which will join DCP under the same Programmable Company project.

Estonia profile skeleton added under [`profiles/estonia/`](profiles/estonia/). Specification Enhancement Proposal (SEP) template added under [`seps/`](seps/).

## 2026-04-22

Initial public repository. Vision and principles published; specification work to follow.
